# Active study — reveal-after-attempt view

Load this view only after the learner has attempted the active question, said
`não sei`, or explicitly requested exposition first. It is intentionally
separate from `ACTIVE_STUDY_QUESTION_FIRST.md`; do not read it in order to
compose the first intervention in default active mode.

## Post-attempt delivery

After acknowledging the attempt, disclose only what is useful for the current
block, normally in this order:

1. correction and the decisive variable;
2. anchor words;
3. initial versus definitive conduct, including complete protocol and doses
   when the source and clinical-validity state support them;
4. traps and seductive distractors;
5. minimum cards or error note, only if they prevent a demonstrated error;
6. an observable stopping condition and the next single block.

Separate `curricular/material historical` from `current clinical practice`
when sources diverge. A critical claim without current clinical validity stays
quarantined for assertive conduct.

## Diagnostic discipline

Use the learner's actual production, not the fact that a question was shown.
One attempt can create at most a `candidate` hypothesis. An incomplete or
ambiguous item does not support a learner diagnosis. An explicit `acertei,
mas chutei` is an acerto frágil and neither confirms nor refutes the hypothesis.
If the evidence does not identify a movement, record `INDETERMINADO`.

Do not reopen the whole capsule or add unrelated blocks. If the learner asks
for a new representation after a real misunderstanding, change the
representation while preserving the active target and stopping condition.
